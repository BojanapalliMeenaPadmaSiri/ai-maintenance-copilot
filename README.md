# AI Maintenance Copilot

An AI-powered maintenance assistant that combines:

- Maintenance manuals
- Sensor event data
- Image evidence
- Gemini 2.5 Flash

## Features

- RAG-based document retrieval
- Sensor analysis
- Image-based fault detection
- Maintenance recommendations

## Technologies

- Python
- Gemini 2.5 Flash
- FAISS
- Sentence Transformers
- Pandas
